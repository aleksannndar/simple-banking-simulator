# Use of AI

AI was used as a supporting tool throughout this project.

After receiving the initial task requirements, I expanded them into more detailed rules and constraints. I then worked on the initial design and chose the main principles I wanted the project to follow. These included using value objects, defining interfaces for the repository and transaction manager so that an in-memory implementation could later be replaced with a database-backed one, and using specific exceptions for different failure cases, etc. I shared this design with AI to review it, discuss tradeoffs, and identify anything that might need to change.

During implementation, I used AI to generate some of the boilerplate code. I also used it as part of the testing process. In some cases, I defined the test scenarios and asked AI to generate an initial version of the tests, which I then reviewed and corrected. In other cases, I asked AI to suggest tests for a function and then added, removed, or modified cases based on what was relevant.

After completing the project, I used AI for a final review to look for missing cases and possible improvements.

All AI-generated code and tests were reviewed and adjusted before being included in the project.
