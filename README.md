# Simple Banking Simulator

A framework-free banking component built with Java 25 and Maven.

## Prerequisites

- JDK 25 or newer

The included Maven wrapper downloads the project-pinned Maven version automatically.

## Build

On Windows:

```powershell
.\mvnw.cmd verify
```

On macOS or Linux:

```shell
./mvnw verify
```

The `verify` command compiles the project and runs all tests.
